## ⭐ Projetos em destaque

### 👻 Schematic Ghost — Minecraft Mod

Mod client-side desenvolvido para **Minecraft 26.3 com Fabric**, que permite visualizar schematics dentro do jogo usando blocos fantasmas translúcidos e contornos para identificar blocos ausentes ou incorretos.

**Principais recursos:**
- 📂 Leitura de arquivos `.litematic` e `.schem`.
- 🧱 Comparação do schematic com os blocos do mundo.
- 👻 Visualização de blocos fantasmas com suas texturas.
- 🎯 Contornos coloridos para identificar blocos faltantes ou incorretos.
- 🖥️ Interface própria para configurar o mod.
- ⌨️ Tecla de atalho e comandos de cliente.
- 🔍 Leitura de NBT e processamento de paletas compactadas.

**Tecnologias:** Java 25, Minecraft 26.3, Fabric Loader, Fabric API, Gradle, Fabric Loom e Brigadier.

O mod funciona exclusivamente no cliente, sem colocar blocos automaticamente ou enviar ações de construção ao servidor.


### 💈 Barbearia Prime — App mobile de agendamento

Aplicativo mobile para barbearias, com agendamento de horários e gestão de clientes.

**Principais recursos:**
- 📅 Agendamento de horários.
- 👥 Gestão de clientes.
- 🔐 Backend com banco de dados em nuvem.
- 📲 Build Android distribuída via EAS (APK).

**Tecnologias:** React Native, Expo, TypeScript e Supabase.  


### 💇 Studio Agenda Pro — Gestão para profissionais de beleza

Sistema voltado à gestão de salões e profissionais de beleza, com foco na organização da agenda, clientes, serviços e finanças, além de facilitar o agendamento pelos clientes.

**Foco do projeto:**
- 📅 Gerenciamento de agendamentos.
- 👥 Cadastro e organização de clientes.
- 💰 Controle financeiro.
- ✂️ Gestão de serviços e produtos.
- 🔗 Agendamento online.

🌐 [Acessar o Studio Agenda Pro](https://www.studioagendapro.com.br/)


### 🤖 Bots e sistemas personalizados

Desenvolvimento de bots para Discord e soluções para comunidades e servidores de FiveM, incluindo sistemas de gerenciamento, automações e funcionalidades personalizadas.
